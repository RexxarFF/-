Проверка версии 0.2.3 — 16.10.2026

python -m unittest discover -s tests -v
Результат: 140 тестов, все пройдены.

Покрыты: расчёт дат и подгрупп; отдельные повторные уроки; права;
изоляция классов и личных записей; параллельные правки; личный ответ из группы;
объявления; напоминания; огоньки; формат запросов Telegram и обработка ошибок.

Тесты выполнены без настоящего токена. Внешний Telegram имитируется.
Реальная доставка сообщений проверяется после настройки BOT_TOKEN.

Исправление для Bothost: добавлен запуск через main.py,
python -m classdiary и python -m classdiary.app.
Все четыре точки запуска проверены отдельными процессами с --check.
Без токена модуль теперь выдаёт понятную ошибку, а не молча завершается.

0.1.1: плоская упаковка для Bothost; main.py в корне, ранние сообщения о запуске.
Добавлен сквозной тест: запуск runner → getUpdates → /start → личное меню.
Telegram в этом тесте имитируется, сетевое подключение хостинга он не проверяет.

0.2.0: проверены редактирование единственной панели, продолжение после перезапуска,
удалённое сообщение, отсутствие лишних сообщений при ошибках редактирования,
очистка временных фото, страницы длинных заданий и повторная проверка доступа,
календарь на границе годов, сохранение черновика при смене даты,
недельное расписание, обычные фразы из группы, мгновенная публикация объявления,
экранирование имён в упоминаниях, отсутствие повторной отправки в группу,
точная граница 14 дней, личное ДЗ, будущие сроки и часовые пояса.

Миграция проверена на схеме, извлечённой из выпущенного ZIP 0.1.1:
класс, привязка группы, роли, домашка, отметки и черновик сохранены.
Повторный запуск миграции безопасен; PRAGMA integrity_check / foreign_key_check пройдены.

0.2.1: добавлены проверки ответа для непривязанной группы, диагностической команды,
настроек Privacy Mode и статуса администратора, команд от имени группы,
отсутствия выдачи данных анонимным отправителям и настоящим ботам,

игнорирования обращений к другим ботам, логов получения без текстов сообщений.

0.2.2: воспроизведено, что прежняя версия не отправляла новое сообщение в личку
при запросе из группы, а редактировала старую панель. Регрессионные проверки
теперь требуют настоящую отправку sendMessage для команды и групповой кнопки.
Проверены: новый ответ и «Назад» в нём; страницы длинного ДЗ; сохранение старой
панели при неуспешной отправке; ошибка удаления старой панели; ошибки 403/429/0/400;
ошибка подтверждения в группе без повторной отправки в личку; /my без публикации
личных записей в группе; темы группы; паузы для одного чата и независимость
других чатов; один повтор короткого 429 без бесконечных попыток.

Сквозная проверка запускает polling, права, формирование ДЗ, сохранение состояния
панели и настоящий класс транспорта. На границе HTTP ответы Telegram имитируются.
Проверены последовательные /start в личке, /menu и /hw в группе, групповая кнопка
и «Назад» в личке. Две операции из группы дают два новых API-запроса sendMessage
с настоящим текстом задания; «Назад» даёт editMessageText нового ответа.

0.2.3: проверена маршрутизация команд, естественных фраз и кнопок группового меню:
статистика и огоньки отправляются в группу, учебные данные — в личку.
Проверены работа интерактива при заблокированной личке, сохранение личной панели
и черновика, обновление групповой карточки, защита кнопок другого участника,
приглашение и согласие в группе без личных уведомлений, отказ и удаление огонька,
отсутствие повторных приглашений, отключённый интерактив, чужие классы,
длина callback_data, страницы и темы группы. Сквозной сценарий polling дополнен
запросами /stats и /pairs между доставками ДЗ; назначения сообщений проверяются.
