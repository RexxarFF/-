КЛАССНЫЙ ДНЕВНИК — ПЕРВЫЙ ЗАПУСК

1. Распакуйте весь ZIP в отдельную папку.
2. Нужен Python 3.11 или новее. При установке в Windows включите Add Python to PATH.
3. В Telegram откройте @BotFather, отправьте /newbot и создайте бота.
4. Скопируйте файл .env.example в .env и вставьте токен после BOT_TOKEN=.
   В Windows можно открыть PowerShell в папке проекта и выполнить:
       Copy-Item .env.example .env
       notepad .env
5. Запустите start.bat в Windows или python3 run.py в Linux.
6. Откройте своего бота в Telegram, нажмите «Начать», затем «Создать класс».
7. Введите 9Б. Нажмите «Загрузить расписание 9Б» и подтвердите загрузку.
8. Управление классом → Участники → Выбрать участников.
9. Выбранные участники открывают бота и нажимают «Начать».
10. Ответственным выдайте роль «Ответственный за ДЗ» через карточку участника.

Сторонние библиотеки устанавливать не нужно. requirements.txt оставлен для хостингов.
В ZIP нет действующего токена и нет вашей заполненной базы данных.

ВАЖНО ПО ФОТО РАСПИСАНИЯ
Предметы, время и повторные уроки перенесены с фотографии.
Распределение по подгруппам в фото не подписано. Предварительно первый
предмет в ячейке через / отнесён к Группе 1, второй — к Группе 2.
Проверьте это: Управление классом → Редактор расписания → нужный день.
В понедельник английский добавлен для обеих подгрупп в одно время.
У каждого ученика есть «Мои подгруппы». До выбора он видит все варианты.

Полная инструкция, настройка группы и хостинга — в README.md.
