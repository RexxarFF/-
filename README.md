# Классный дневник · 0.2.3

Telegram-бот для нескольких классов. У каждого класса отдельные участники, права,
расписание, общая домашка, объявления и группа. Личные записи ученика отделены от общих.

Проект использует Python 3.11+ и стандартную библиотеку. Установка пакетов не нужна.
Данные и незаконченные черновики хранятся в SQLite, а не в JSON-файле.

## Обновление 0.2.3: статистика и интерактив в группе

Ответы на запросы из привязанной группы теперь приходят по разделам:

| Запрос | Куда приходит ответ |
| --- | --- |
| `/stats`, «моя статистика» | В группу: сообщения, личная серия и активность класса |
| `/pairs`, `/interactive`, «огоньки» | В группу: парные огоньки и управление приглашениями |
| `/hw`, `/my`, `/schedule`, запросы о домашке и расписании | В личку отправителю запроса |

Кнопки группового меню работают по тем же правилам. Карточки интерактива обновляются
в группе; они не меняют личную панель и незаконченный черновик ДЗ. В теме группы
новые ответы приходят в ту же тему. Групповые приглашения в парные огоньки
публикуются в группе; принять приглашение может только адресат. Остальные действия
с личной карточкой огоньков доступны владельцу этой карточки.

Команды, отправленные в личке, по-прежнему открывают личный интерфейс.
При обновлении сохраните `.env` и `data`, замените исходники и выполните новый деплой.

## Исправление 0.2.2: ответ из группы не появлялся в личке

В версиях 0.2.0–0.2.1 запрос из группы редактировал старое сообщение в личке.
Это могло выглядеть как отсутствие ответа. Теперь команда или кнопка в группе
отправляет **новое сообщение в личку**. Только после успешной отправки бот пытается
удалить прежнюю панель навигации. Если Telegram не разрешает её удалить, новая
панель всё равно работает. Дальнейшие кнопки в личке редактируют новую панель.

- На текстовый запрос в группе бот подтверждает успешную доставку. Домашка остаётся в личке.
- `/my` теперь работает и в группе: личные записи получает только отправитель запроса.
- Недоступная личка, отсутствие доступа к классу, ошибка форматирования, сетевой сбой
  и ограничение частоты отправки показываются разными сообщениями.
- Добавлены интервалы отправки для одного чата и повтор короткого ограничения Telegram.
  Долгое ограничение показывается пользователю; сетевые ошибки автоматически не
  повторяются, чтобы не продублировать уже принятую Telegram отправку.
- В группах с темами подтверждения и меню приходят в ту тему, где задан вопрос.
- Лог `Group private reply sent` появляется после подтверждённой отправки в личку;
  `Group private reply failed` содержит категорию ошибки без текста домашки.

Обновление исходников не меняет классы, привязки, расписание и сохранённые задания.

  если срок выполнения уже прошёл. Задания на сегодня и будущие даты сохраняются.

Для обновления сохраните прежние `.env` и каталог `data`, замените исходники и
выполните новый деплой. Таблицы существующей базы обновляются автоматически.
Пошаговая инструкция — в `UPDATE_0.2.0.txt`.

## Быстрый запуск в Windows

1. Распакуйте ZIP целиком.
2. Установите Python 3.11 или новее с включённой опцией **Add Python to PATH**.
3. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`.
4. В папке проекта скопируйте `.env.example` в `.env`. В PowerShell:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

5. В `.env` замените `PASTE_YOUR_BOT_TOKEN_HERE` настоящим токеном.
6. Запустите `start.bat`. Пока окно работает, бот доступен.
7. В Telegram откройте своего бота → **Начать → Создать класс**.
8. После создания загрузите подготовленное расписание 9Б или заполните своё.

Токен не нужно присылать в чат. Он остаётся в вашем `.env` или переменных хостинга.

## Linux и хостинг

```bash
cp .env.example .env
# Вставьте токен в .env любым текстовым редактором.
python3 run.py
```

На хостинге с переменными окружения достаточно указать `BOT_TOKEN` и команду запуска
`python run.py`. Также работают `python main.py`, `python -m classdiary` и
`python -m classdiary.app` — последний вариант используется автоопределением Bothost.
Файл `.env` тогда не обязателен. Порт, домен и HTTPS-сертификат не нужны:
бот использует long polling и исходящие запросы к `api.telegram.org`.

Для Bothost выберите Python 3.11+ и постоянное хранение каталога `data`.
В настройках бота раскройте **Дополнительные настройки** и в поле
**Главный файл (точка входа)** укажите `main.py`, затем сохраните и выполните новый деплой.
Это имя файла, а не команда `python main.py`. В этой поставке файлы лежат прямо в корне ZIP.
Подробные шаги — в `BOTHOST_START.txt`.
Предупреждения его сборщика об отсутствии `aiogram` и `python-dotenv` не относятся к
зависимостям этого проекта: используется стандартная библиотека и собственное чтение `.env`.
Проект не требует веб-сервера. С одним токеном запускайте один экземпляр.
Если хостинг стирает файлы при перезапуске, сохраните базу на постоянном диске.

Docker, если он уже установлен:

```bash
docker compose up -d --build
docker compose logs -f
```

`compose.yaml` создаёт постоянный том для базы. `.env` не включается в образ.

## Настройки

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | — | Токен от BotFather |
| `DATABASE_PATH` | `data/diary.sqlite3` | Файл базы; относительный путь считается от папки проекта |
| `DEFAULT_TIMEZONE` | `Europe/Moscow` | Пояс новых классов |
| `MAX_CLASSES_PER_OWNER` | `10` | Лимит классов, созданных одним человеком |
| `HOMEWORK_RETENTION_DAYS` | `14` | Хранение старого ДЗ в днях после создания записи; 1–365 |

Часовой пояс отдельного класса меняется через его настройки. Поддерживаются IANA-пояса
при наличии системной базы часовых поясов, а также смещения вида `+03:00`. Москва и UTC
работают в том числе в Windows без дополнительных пакетов. Для других IANA-поясов в
Windows можно установить `tzdata` или указать смещение; фиксированное смещение не
переключается автоматически на летнее время.

## Создание классов и участники

Любой человек может создать свой класс. Названия вроде «9Б» могут повторяться: классы
различаются внутренним ID. Создатель получает все права только в своём классе.

**Управление классом → Участники → Выбрать участников** открывает стандартное окно
Telegram. За один выбор можно отметить до 10 человек; выбор можно повторять.
Есть добавление по Telegram ID и по контакту, в котором Telegram передал ID пользователя.
Телефонные номера не используются и не сохраняются.

Участник должен сам открыть бота и нажать **Начать**. Выбор человека в окне контактов
не разрешает боту первым писать ему в личку. Для выбранных участников владелец получает
ссылку на класс. Постороннего человека одна ссылка в класс не добавляет.

Один пользователь может состоять в нескольких классах. Активный класс выбирается
кнопкой **Мои классы**. При переключении незаконченный ввод отменяется.

## Роли

По умолчанию создаются две роли: «Ответственный за ДЗ» и «Редактор расписания».
Обычному ученику роль для просмотра и личных записей не требуется.

Владелец может создавать, переименовывать и удалять роли, менять их права и выдавать
несколько ролей одному участнику. Права складываются. Назначение и снятие ролей — в
карточке участника; создание и изменение — в разделе **Роли и права**.

| Право | Возможности |
| --- | --- |
| Общее ДЗ | Добавление, исправление, удаление общей домашки |
| Расписание и замены | Недельное расписание и изменения на конкретные даты |
| Объявления | Создание объявлений и просмотр отметок «Ознакомился» |
| Участники | Добавление и исключение людей |
| Роли и права | Управление ролями и назначениями |
| Настройки и привязка группы | Часовой пояс, группа, включение интерактива |

Права проверяются при выполнении каждого действия, включая сохранение уже открытого
черновика. Если роль сняли, сохранить общее ДЗ больше нельзя. Владелец не имеет доступа
к личным заданиям других участников через интерфейс бота.

## Как записывается ДЗ

1. Ответственный нажимает **Записать общее ДЗ**.
2. Бот показывает предметы сегодняшнего дня по часовому поясу класса. Можно выбрать
   другой день в календаре — именно тот, когда задание задали.
3. Выбирается конкретный урок и подгруппа. Даже два одинаковых предмета в один день
   имеют разные записи.
4. Дата выполнения автоматически предлагается на следующую дату с этим предметом и
   подходящей подгруппой. Второй такой же урок в день записи автоматически не выбирается.
5. Ответственный присылает текст и материалы. Несколько сообщений добавляются в один
   черновик. Альбом Telegram приходит несколькими вложениями.
6. Черновик обновляется в том же сообщении. Нажмите **Сохранить**. Бот снова покажет предметы дня и
   отмечает заполненные уроки.

Например, английский группы 1 в среду переносится к следующему английскому группы 1.
Если ближайшее занятие группы 2 раньше, оно на расчёт группы 1 не влияет.

Можно выбрать дату выполнения в календаре. При двух одинаковых предметах номер
занятия выбирается кнопкой через **Ещё / исправить → Выбрать урок к сдаче**. Если в
расписании нет следующего такого предмета, бот открывает календарь. Каникулы и отмены учитываются,
если они внесены как замены на конкретные даты. Поиск следующего урока ограничен 370 днями.

Текст: до 6000 символов; вложения: до 20. Поддерживаются фото, документы, видео, аудио,
голосовые, анимации и видеосообщения. Файлы привязаны к записи через Telegram `file_id`.
Для получения материалов ученик открывает соответствующее задание.

При повторном открытии заполненного урока редактируется существующее задание. Новый текст
добавляется к текущему; для полной замены нажмите **Ещё / исправить → Очистить текст**.
Два ответственных не смогут молча перезаписать параллельные правки: при конфликте второй
получит предложение открыть актуальную запись заново.

**Ничего не задано** выставляется отдельной кнопкой. Без записи отображается
**ДЗ пока не записано** — это разные состояния.

Домашка сохраняется без автоматической отправки в группу. На выбранную дату бот
собирает единый список; **Обновить** получает его актуальную версию в том же сообщении.
Открытый список другого ученика обновится при его следующем нажатии, а не сам по себе.

## Личные записи и просмотр

- **Общее ДЗ на завтра** — задания ответственных, отдельно от личных заметок.
- **Мои записи** — только собственные задания на выбранную дату.
- **Записать себе** — запись по уроку либо произвольный предмет или заметка.
- **Расписание** — вся неделя с переходами к отдельным дням; в подробностях есть время и кабинеты.
- Во всех списках можно выбрать другую дату, сегодня, завтра и перейти стрелками.
- **Выполнено** — личная отметка ученика. После изменения задания отметка сбрасывается.

Личные записи не попадают в общую домашку и в группу. Исключение ученика из класса
удаляет его личные записи в этом классе; это действие подтверждается.

## Расписание из фотографии

Шаблон `templates/9b.json` уже содержит дни и звонки с присланного фото. Его можно
загрузить через кнопку после создания класса либо **Управление → Загрузить расписание 9Б**.
Для чужих классов шаблон не применяется автоматически.

Сохранены пустые первые уроки в пятницу и субботу: занятия начинаются со второй строки
расписания в 09:00. Во вторник две алгебры, в четверг две геометрии и в пятницу две физики
внесены разными уроками.

**Распределение подгрупп на фото не указано.** Предварительно первый предмет каждой
ячейки через `/` отнесён к «Группе 1», второй — к «Группе 2». В понедельник английский
есть для обеих групп в одно время. ВУД с несколькими вариантами — отдельные группы по
предметам. Предупреждение об этом показывается перед загрузкой шаблона.
При необходимости поменяйте названия групп или предметы в редакторе нужного дня.

**Мои подгруппы** позволяют ученику выбрать свои занятия. Общие уроки видны всегда.
Если ничего не выбрано, бот показывает все подгруппы, чтобы до уточнения ничего не скрывать.
Ответственный при записи общей домашки всегда видит все уроки и группы класса.

Автоматическое распознавание новых фотографий в эту версию не входит; ваше расписание
перенесено вручную и уже включено в проект.

## Редактор расписания и замены

**Управление → Редактор расписания → день недели**. Пришлите весь день одним сообщением:

```text
1; Алгебра; ; 09:00-09:45; 12
2; Английский язык; Группа 1; 10:05-10:50; 23
2; Информатика; Группа 2; 10:05-10:50; 7
3; Русский язык
```

Формат: `номер; предмет; подгруппа; начало-конец; кабинет`. Необязательные поля можно
пропускать, сохраняя разделители при необходимости. Пустая подгруппа означает весь класс.
Для выходного отправьте `выходной`. Прежде чем заменить день, бот покажет предпросмотр.

**Замена на дату** меняет только выбранную дату. Можно отменить уроки или выставить
другое расписание; кнопка **Убрать замену на дату** возвращает недельный шаблон.
Изменение расписания не переносит уже сохранённые задания автоматически. Их сроки
при необходимости меняются через карточку задания, чтобы старые записи не исчезали.

## Работа в группе

**Управление → Привязать группу → Добавить бота в группу**. Привязать её может человек,
у которого есть право настроек класса и статус администратора этой группы. Если бот
уже добавлен, можно выбрать существующую группу стандартным окном Telegram.

Одна группа привязывается к одному классу. В группе вызовите `/menu`: появятся кнопки
общего ДЗ, расписания, статистики и огоньков. ДЗ и расписание приходят нажавшему
новым сообщением в личку. Статистика и огоньки показываются в группе.
Если личка недоступна, бот предложит ссылку для её открытия.

Можно написать обычным текстом: **что задано на завтра**, **ДЗ на сегодня**,
**расписание на завтра** или **расписание на неделю**. Ответ придёт новым сообщением
этому пользователю. «Моя статистика» и «огоньки» открывают карточки в группе.
Бот распознаёт эти явные запросы; произвольный разговор не анализирует.

Участие в группе само по себе не даёт доступа к классу: человека должен добавить
владелец или участник с соответствующим правом. Личные записи через групповое меню
не публикуются. Неизвестные сообщения в группе бот игнорирует, сохраняя только счётчик
доступных ему сообщений участников при включённом интерактиве.

Чтобы бот видел обычные фразы и сообщения для статистики, назначьте его администратором либо
отключите **Group Privacy / Privacy Mode** у BotFather и повторно добавьте бота в группу.
Без этого команды и кнопки работают, но обычные фразы и полная статистика недоступны.

## Объявления и напоминания

Объявление создаётся человеком с правом **Объявления**: текст и материалы → предпросмотр
→ подтверждение публикации. Оно сохраняется, и бот сразу пытается отправить его
в привязанную группу. Личные уведомления активным участникам доставляются через очередь.
В группе используются именные ссылки-упоминания участников из списка класса,
включая тех, кто ещё не запускал бота. В Telegram Bot API нет универсальной команды
`@all`: участники группы вне списка класса не отмечаются. Появление уведомления
зависит от Telegram и личных настроек пользователя. Ошибки Telegram и ограничения частоты
обрабатываются с повторными попытками. Удалённому из класса человеку сообщение не
отправляется. При сетевой неопределённости повторная доставка может дать дубликат.

Кнопка **Ознакомился** фиксирует нажатие; это не автоматический отчёт о прочтении.
Автор с соответствующим правом может посмотреть отметившихся. Последние 30 объявлений
доступны из меню. Редактирование и удаление опубликованных объявлений пока не добавлены.

Ученик сам включает **Личные напоминания** и указывает время. Время учитывается по
каждому классу. Напоминание ведёт к общему ДЗ, своим записям и расписанию на завтра.
Если на завтра нет уроков и доступных ему заданий, напоминание не отправляется.
Уникальная запись в очереди предотвращает повторное создание напоминания за одну дату.

## Срок хранения домашки

Раз в час бот удаляет общие и личные задания старше `HOMEWORK_RETENTION_DAYS` дней.
Отсчёт идёт от создания записи, а не от даты урока. Правки не продлевают срок.
Задания с датой выполнения сегодня или позже остаются до наступления следующего дня.
Вместе с удалённым заданием убираются его отметки выполнения и ссылки на вложения
из базы. Объявления и расписание эта очистка не удаляет. Уже отправленные сообщения
Telegram и сами файлы Telegram из базы удалить нельзя.

Для записей из версии 0.1.1, где отдельной даты создания не было, при обновлении
используется сохранённая дата последнего изменения. Каталог базы остаётся прежним.

## Интерактив

- Личная статистика сообщений: сегодня, последние 7 дней, всё время учёта.
- Список 10 активных участников за последние 7 дней.
- Личный огонёк: хотя бы одно сообщение в группе за календарный день.
- Парный огонёк: приглашение второму участнику, его согласие и дни, когда писали оба.
- Пустой текущий день ещё не сбрасывает серию; пропущенный завершившийся день сбрасывает.
- Правки сообщений не считаются новыми; повторная обработка одного сообщения не удваивает счётчик.

Дни считаются по часовому поясу класса, включая выходные. Участники вне списка класса и
сообщения ботов не учитываются. История до подключения не импортируется. Текст групповых
сообщений для статистики не сохраняется: остаются ID, дата и автор. Владелец может
отключить интерактив в настройках. Учебные достижения и мини-игры в этот выпуск не входят.

## Проверки и резервная копия

Проверка комплекта без сети и токена:

```bash
python run.py --check
python -m unittest discover -s tests -v
```

Тесты проверяют расчёт дат, подгруппы, повторные уроки, разделение личных и общих записей,
права, конфликты редактирования, личные ответы из группы, объявления и напоминания.
Внешний Telegram в тестах заменён имитатором. Работа с вашим настоящим ботом проверяется
после ввода токена; действующий токен в архив не включён.

Согласованная резервная копия SQLite:

```bash
python run.py --backup backups/diary-backup.sqlite3
```

Перед восстановлением остановите бота, замените основной файл базы резервной копией
и уберите оставшиеся файлы `diary.sqlite3-wal` / `diary.sqlite3-shm` от старой базы.
Не удаляйте каталог `data` при обновлении исходников.

| `run.py` | Запуск, long polling, команды, проверка и резервное копирование |

| `classdiary/group_requests.py` | Распознавание запросов из группы |
